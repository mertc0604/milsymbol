      Using the symbol editor

      Select a standard, open the search with the bar at the top (or /), then configure the symbol, its text amplifiers and its graphics. The preview and SIDC update as you edit.

      In the search, ↑ ↓ move between results, Enter selects and Esc clears the search, then closes it. A full SIDC typed into the search finds its symbol.

      Paste a code into the Symbol identification code box and press Enter or Apply. Esc returns to the current code. In codes copied from a publication, * keeps the current identity or status. Messages below the box explain what was applied or why a code was rejected.

      Edit text, under the preview, opens Text amplifiers in Field positions: a box for each field around the symbol, in the order the standard places it (the boxes are spaced apart for typing; the preview shows the exact placement). The List view shows the fields that apply to the symbol, with their rules and tools; the others are listed, closed, under it. SVG is a scalable vector file; PNG is exported with a transparent background. Copying the SIDC alone does not include text or appearance settings.

      MIL-STD-2525C and APP-6A/B use letter-based codes. The later editions use numeric codes. APP-6E uses the shared 2525E catalog here, with milsymbol's rendering conventions. It is a compatibility view, not a separate edition-specific catalog. Echelon and mobility are unspecified until selected.
