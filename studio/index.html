Using the symbol editor

Select a standard, search the library, then configure the symbol and its text amplifiers. The preview and SIDC update as you edit.

Use / to search and Esc to clear the search. SVG is a scalable vector file; PNG is exported with a transparent background.

MIL-STD-2525C and APP-6A/B use letter-based codes. The later editions use numeric codes. Text amplifiers are grouped by purpose and include field identifiers and guidance. They are included in SVG and PNG exports; copying the SIDC alone does not include text or appearance settings.

APP-6E uses the shared 2525E catalog here, with milsymbol's rendering conventions. It is a compatibility view, not a separate edition-specific catalog. Echelon and mobility are unspecified until selected.
